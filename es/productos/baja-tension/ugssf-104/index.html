Resumen

UGSSF 104; Split-core type current transformer for outdoor use.

Standard accessories:

aluminium terminal box

Cable gland, PA, M16x1.5 for cable Ø 5…10,

on request M20x1.5 for cable-Ø 8…13

Size 1: W / H / L: 110 / 147/ 92 mm*

Size 2: W / H / L: 110 / 147 / 132 mm*

*(incl. terminal box)

Optional accessories:

Terminal box made of PETP

Cable gland, PA, M20x1.5 for cable Ø 8…13,

on request M25x1.5 for cable-Ø 11…17

Size 1: W / H / L: 110 / 169 / 92 mm*

Size 2: W / H / L: 110 / 169 / 132 mm*

*(incl. terminal box)

2 mounting feet

2 cable fixing devices

1 wall bracket

Weight: varies

Mounting in any position

The current transformer is maintenance-free

Los datos de producto están disponibles en inglés y alemán.

Características

  • Resina colada
  • Aislamiento de resina colada
  • Clase de aislamiento E (120 °C)
  • Transformador de medida BT
  • Transformador de protección BT
  • Exterior
  • Monofásico
  • Temperatura ambiente −25 … +40 °C
  • Declaración de conformidad / verificable
