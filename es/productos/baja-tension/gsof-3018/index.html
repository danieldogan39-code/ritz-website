Resumen

GSOF 3018 Outdoor window type current transformer.

possible model options:

Inner Ø 180 mm for Cable up to Ø 180 mm

Size 1: W / H / L: 300 / 362 / 110 mm*

Size 2: W / H / L: 300 / 362 / 160 mm*

Size 3: W / H / L: 300 / 362 / 200 mm*) incl. terminal box;

Special designs:

Um 1.2 kV or 3.6 kV

Installation without support only in upright or lying position only.

Accessories:

Terminal box lid of aluminium

Optional accessories:

mounting plate

wall bracket

Los datos de producto están disponibles en inglés y alemán.

Características

  • Transformador de medida BT
  • Exterior
  • Monofásico
  • Temperatura ambiente −25 … +40 °C
  • Declaración de conformidad / verificable
