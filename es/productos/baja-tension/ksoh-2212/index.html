Resumen

(E) KSOH 2212 Indoor single-phase window type current transformers, indoor application

possible design options:

KSOH 2212, height 120 and 80 mm, connecting cable DIN 57281 H07V-K1X4, length according to order (PO)

Los datos de producto están disponibles en inglés y alemán.

Características

  • Interior
  • Transformador de medida BT
  • Montaje en cualquier posición
  • Monofásico
  • Temperatura ambiente −5 … +70 °C
  • Apto para clima tropical
  • Declaración de conformidad / verificable
