Resumen

KSW ... Series, Indoor winding type current transformer, Standard series, Black Series.

possible design options:

KSW 65, Primary Current 5…75A, External dimensions (W/H/L): 60 / 117 / 52 mm

KSW 73, Primary Current 10…200A, External dimensions (W/H/L): 70 / 91 / 74 mm

KSW 104, Primary Current 15…300A, External dimensions (W/H/L): 100 / 124 / 92 mm

Standard accessories: 2 foot attachments.

Mounting in any position.

Los datos de producto están disponibles en inglés y alemán.

Características

  • Interior
  • Transformador de medida BT
  • Montaje en cualquier posición
  • Monofásico
  • Temperatura ambiente −5 … +40 °C
  • Apto para clima tropical
  • Declaración de conformidad / verificable
