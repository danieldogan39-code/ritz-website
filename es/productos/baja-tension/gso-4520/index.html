Resumen

GSO 4520 Indoor window type current transformer.

possible model options:

Inner Ø 205 mm for Cable up to Ø 205 mm

Size 1: W / H / L: 450 / 504 / 100 … 400 mm *) incl. terminal cover;

Special designs:

Um 1.2 kV or 3.6 kV

Installation without support only in standing or horizontal Position.

Accessories:

transparent Terminal cover

Los datos de producto están disponibles en inglés y alemán.

Características

  • Interior
  • Transformador de medida BT
  • Monofásico
  • Temperatura ambiente −5 … +40 °C
  • Declaración de conformidad / verificable
