Resumen

GSO 2505 Indoor window type current transformer.

possible model options:

Inner Ø 55 mm for Cable up to Ø 55 mm

Size 1: W / H / L: 250 / 280 / 75 mm*)

Size 2: W / H / L: 250 / 280 / 100 mm*)

Size 3: W / H / L: 250 / 280 / 135 mm*)

Size 4: W / H / L: 250 / 280 / 170 mm*)

Size 5: W / H / L: 250 / 280 / 340 mm*) incl. terminal cover;

Special designs:

Um 1.2 kV or 3.6 kV

Installation without support only in upright or lying position only.

Accessories:

transparent terminal cover

Optional accessories:

mounting plate

wall bracket

Los datos de producto están disponibles en inglés y alemán.

Características

  • Interior
  • Transformador de medida BT
  • Monofásico
  • Temperatura ambiente −5 … +40 °C
  • Declaración de conformidad / verificable
