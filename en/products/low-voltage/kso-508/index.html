Overview

KSO 508 Indoor: Window Type Current Transformer without primary conductor, standard series,

Inside Ø 82 mm for round cables up to Ø 82 mm

Size W/H/D: 150 / 161 / variable mm;

Special designs:

Up to 1.2 kV

tropical design

Cast resin filling with tropical strength

Accessories:

transparent terminal cover

4 Foot mountings

Mounting in any position

The current transformer is maintenance-free

Features

  • Indoor
  • LV metering transformer
  • Mounting in any position
  • Single-phase
  • Ambient temperature −5 … +40 °C
  • Declaration of conformity / verifiable
