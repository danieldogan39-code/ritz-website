Overview

(E) KSOH 2212 Indoor single-phase window type current transformers, indoor application

possible design options:

KSOH 2212, height 120 and 80 mm, connecting cable DIN 57281 H07V-K1X4, length according to order (PO)

Features

  • Indoor
  • LV metering transformer
  • Mounting in any position
  • Single-phase
  • Ambient temperature −5 … +70 °C
  • Suitable for tropical climates
  • Declaration of conformity / verifiable
