Overview

UGSSF 305; Split-core type current transformer for outdoor use.

Standard accessories:

aluminium terminal box

Cable gland, PA, M16x1.5 for cable Ø 5…10,

on request M20x1.5 for cable-Ø 8…13

Size 1: W / H / L: 135 / 172/ 92 mm*

Size 2: W / H / L: 135 / 172 / 132 mm*

*(incl. terminal box)

Optional accessories:

Terminal box made of PETP

Cable gland, PA, M20x1.5 for cable Ø 8…13,

on request M25x1.5 for cable-Ø 11…17

Size 1: W / H / L: 135 / 194 / 92 mm*

Size 2: W / H / L: 135 / 194 / 132 mm*

*(incl. terminal box)

2 mounting feet

2 cable fixing devices

1 wall bracket

Weight: varies

Mounting in any position

The current transformer is maintenance-free

Features

  • Cast resin
  • Cast resin insulation
  • Insulation class E (120 °C)
  • LV metering transformer
  • LV protection transformer
  • Outdoor
  • Single-phase
  • Ambient temperature −25 … +40 °C
  • Declaration of conformity / verifiable
