Overview

KSR-S 60 Indoor ring core tube type current sensor

Application:

For measured value acquisition in low-voltage distribution systems. Space-saving design due to integration in NH switchgear rails. With removable copper tube for round conductors up to Ø 16 mm.

Standard accessory: transparent terminal cover.

The current sensor is maintenance-free.

Weight: approx. 1.0 kg
