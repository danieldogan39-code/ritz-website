Überblick

UGSSF 708; Zweiteiliger Kabelumbau-Stromwandler für Freiluft.

Standardzubehör:

Aluminium-Klemmenkasten

Kabelverschraubung, PA, M16x1,5 für Kabel-Ø 5…10,

auf Wunsch M20x1,5 für Kabel-Ø 8…13

Größe 1: B / H / L: 170 / 207 / 92 mm*

Größe 2: B / H / L: 170 / 207 / 132 mm*

*(inkl. Klemmenkasten)

Sonderzubehör:

Klemmenkasten aus PETP

Kabelverschraubung, PA, M20x1,5 für Kabel-Ø 8…13,

auf Wunsch M25x1,5 für Kabel-Ø 11…17

Größe 1: B / H / L: 170 / 229 / 92 mm*

Größe 2: B / H / L: 170 / 229 / 132 mm*

*(inkl. Klemmenkasten)

2 Fußbefestigungen

2 Kabelbefestigungen

1 Wandhalterung

Gewicht: variiert

Montage in beliebiger Position

Der Stromwandler ist wartungsfrei

Merkmale

  • Gießharz
  • Gießharzisolierung
  • Isolierstoffklasse E (120 °C)
  • NS-Messwandler
  • NS-Schutzwandler
  • Freiluft
  • Einphasig
  • Umgebungstemperatur −25 … +40 °C
  • Konformitätserklärung / beglaubigungsfähig
