Tous les outils fonctionnent dans votre navigateur. Les textes, fichiers et résultats ne quittent votre appareil que lorsque vous envoyez une demande.

Comment les outils s’enchaînent

  1. Coller ou calculer le besoin
  2. Types adaptés, avec justification et préconfiguration
  3. Positions, repères et dates dans le dossier projet
  4. Demande avec toutes les données à l’équipe commerciale compétente

Les demandes entrantes peuvent être vérifiées avec les mêmes outils : collez le texte dans la vérification de spécification, puis partagez le résultat sous forme de dossier projet. Chaque demande envoyée via le site web contient un lien qui ouvre le dossier avec toutes les configurations.
