KSE 150 | 0.72 | 1.2 | kV Low voltage indoor voltage transformer, single pole.

Dimensions W/H/L:

Size 1: 150 / 123 / 172 mm

Size 2: 150 / 123 / 182 mm

Size 3: 150 / 123 / 192 mm

Size 4: 150 / 123 / 212 mm

Weight: ≤ 7, 8, 9 or 12 kg, Size 1, 2, 3 or 4

Standard accessories:

2 transparent terminal cover

4 mounting feet,

Possible special versions:

different rated voltage 1.2 kV on request

differing rated frequencies

Tropical version

Filling with cast resin;

Mounting in any position
