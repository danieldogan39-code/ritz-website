Aperçu

GSZR 250 | 0,72 | 1,2 | kV Double-pole insulated voltage transformer for indoor use, low voltage.

Dimensions W/H/L:

Size 1: 110 / 140 / 60 mm,

Size 2: 140 / 170 / 90 mm,

Size 3: 170 / 200 / 120 mm or

Size 4: 210 / 240/ 160 mm.

Weight: varies

Standard accessories:

2 transparent terminal covers

2 foot mounting
