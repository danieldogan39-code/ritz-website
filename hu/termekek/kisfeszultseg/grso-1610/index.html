GRSO 1610 Indoor Window Type Current Transformer Frame Core Design,

Outer dimension: W/H/L: 180 / 120 / 87 mm incl. terminal cover

Aperture: 102 × 22 mm; incl. terminal cover

possible model options:

2 fixing devices for primary conductor,

1 transparent terminal cover
