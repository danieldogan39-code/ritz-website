GRSO 3425 Indoor Window Type Current Transformer Frame Core Design.

possible model options:

Aperture 110x250 mm

Outer dimensions W / H / L: 359 / 200 / 62 or 120 mm; * (size 1 or 2), (*incl. terminal cover)

4 mounting feet

transparent terminal cover
