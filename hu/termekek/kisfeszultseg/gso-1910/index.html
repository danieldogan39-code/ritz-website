GSO 1910 Indoor window type current transformer.

possible model options:

Inner Ø 105 mm for Cable up to Ø 105 mm

Size 1: W / H / L: 190 / 220 / 75, 100, 135, or 170 mm *) incl. terminal cover; (Size 1, 2, 3 or 4)

Special designs:

Um 1.2 kV or 3.6 kV

Installation without support in upright or lying Position only.

transparent Terminal cover

Mounting Plate

Wall Bracket
