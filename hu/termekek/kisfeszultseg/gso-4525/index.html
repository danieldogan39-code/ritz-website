GSO 4525 Indoor window type current transformer.

possible model options:

Inner Ø 250 mm for Cable up to Ø 250 mm

Size 1: W / H / L: 450 / 504 / 100 … 400 mm *) incl. terminal cover;

Special designs:

Um 1.2 kV or 3.6 kV

Installation without support only in standing or horizontal Position.

Accessories:

transparent Terminal cover
