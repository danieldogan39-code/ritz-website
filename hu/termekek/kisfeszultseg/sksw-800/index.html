Áttekintés

SKSW 800 Indoor summation winding-type current transformer Low Voltage in ring core design.

possible model options:

Size: W / H / L: 191 / 185 / variable mm

up to 16 primary circuits

Installation in any position.

Accessories:

4 Foot Mountings,

transparent terminal cover

  • Kisfeszültségű mérési célú mérőváltó

  • Egyfázisú
  • Környezeti hőmérséklet −5 … +40 °C
  • Megfelelőségi nyilatkozat / hitelesíthető
